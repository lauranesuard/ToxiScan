# ToxiScan
**ToxiScan** is a python package to evaluate molecular toxicity, designed for chemists,students, and researchers who need fast and visual toxicity insights.
Given a molecule as input (converted into a SMILES string), ToxiScan: 
  1. Renders the molecule in 3D for an immersive final visualization
  2. Identifies and highlights in color toxic functional groups
  3. Computes a toxicity score based on the detected substructures
