# Data

ToxiScan does not rely on any local dataset. All molecular data is retrieved in real time from the **PubChem** database via its REST API, using the molecule name, IUPAC name, or CAS number as input.

For more information about PubChem, visit [https://pubchem.ncbi.nlm.nih.gov/](https://pubchem.ncbi.nlm.nih.gov/).
